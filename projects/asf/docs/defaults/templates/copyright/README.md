# Copyright Templates

## Overview
This directory contains copyright templates for different types of files in the SpecFirst Development Framework. These templates ensure consistent copyright headers across all project files.

## Template Categories

### 1. Code Files
Templates for programming language files (Python, JavaScript, etc.)

### 2. Documentation Files
Templates for documentation files (Markdown, HTML, etc.)

### 3. Configuration Files
Templates for configuration files (JSON, YAML, etc.)

### 4. Project-Level Files
Templates for project-level files (README, LICENSE, etc.)

## Copyright Header Format

### Standard Format
```
# Copyright (c) 2025, Jaime Moraga (jmoraga@mines.edu)
```

### Extended Format (for code files)
```
# Copyright (c) 2025, Jaime Moraga (jmoraga@mines.edu)
#
# This file is part of the SpecFirst Development Framework.
# See the LICENSE file for details.
```

### Documentation Format (for Markdown files)
```markdown
# Copyright (c) 2025, Jaime Moraga (jmoraga@mines.edu)

# Document Title
```

## Usage Guidelines

### When to Use Copyright Headers
- **All code files**: Python, JavaScript, TypeScript, etc.
- **Configuration files**: JSON, YAML, INI, etc.
- **Documentation files**: Markdown, HTML, etc.
- **Project files**: README, LICENSE, etc.

### When NOT to Use Copyright Headers
- **Generated files**: Auto-generated documentation
- **Temporary files**: Log files, cache files, etc.
- **Third-party files**: External libraries and dependencies
- **User-generated content**: User-created specifications

### Copyright Header Placement
- **Code files**: At the very top of the file
- **Documentation files**: At the very top of the file
- **Configuration files**: At the very top of the file
- **Project files**: At the very top of the file

## Best Practices

### Consistency
- Use consistent copyright header format
- Apply headers to all appropriate files
- Maintain uniform author information
- Keep year information current

### Maintenance
- Regular copyright header reviews
- Update year when making changes
- Validate header accuracy
- Remove headers from inappropriate files

### Compliance
- Follow license requirements
- Include required copyright information
- Maintain license file references
- Ensure proper attribution
